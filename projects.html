  • Hardware Current scope complete ESP32-S3 · PlatformIO

    Weather Atlas

    A finished weather console for M5Stack CoreS3: live conditions, forecasts, radar, ten original themes, and a touch System control center. The device and its local web portal share settings for location, units, Wi-Fi, sound, LEDs, display, and quiet hours. The current feature scope is complete.

    Hiring takeaway: Ships an embedded product end-to-end: responsive touch UI, live data, persistent settings, and a synchronized web control panel.

    Browser install includes firmware, artwork, audio, and web assets. CoreS3 only; Chrome or Edge on desktop with a USB data cable. Uses 2.4 GHz Wi-Fi and Open-Meteo by default; an AccuWeather API key is optional.
