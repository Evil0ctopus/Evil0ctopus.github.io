Flash firmware

Browse the multi-chip firmware catalog, filter by category, then install over USB with ESP Web Tools when a release is ready. Chrome or Edge required (Web Serial). No desktop flasher needed.

Authorized use only. Flash firmware only on hardware you own or are explicitly permitted to install on. wigglefish is metadata-only / passive observation in authorized environments — no joining networks, deauth, or injection. Third-party CYD picks are draft / not wired placeholders: they open an upstream installer and do not activate the local Install button. Android companion app: download from Projects (Wigglefish 0.4.0).

Install guide and recovery
  1. Match the exact board model and display revision. Similar-looking CYD boards can use different chips, displays, and flash layouts.
  2. Use a desktop version of Chrome or Edge over HTTPS, and a known data-capable USB cable.
  3. Back up anything you need. A factory install may erase the board's current firmware and stored data.
  4. Connect only after reviewing the selected firmware's board notes and authorized-use terms. Follow the board maker's boot-mode instructions if prompted.

If a connection fails, disconnect the board, check its exact revision and USB cable, then retry from a fresh browser tab. Do not try a binary intended for a different chip or board variant. Local recovery/build instructions are in each linked project repository.
