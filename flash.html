Flash firmware

Browse the multi-chip firmware catalog, filter by category, then install over USB with ESP Web Tools when a release is ready. Chrome or Edge required (Web Serial). No desktop flasher needed.

Authorized use only. Flash firmware only on hardware you own or are explicitly permitted to install on. wigglefish is metadata-only / passive observation in authorized environments — no joining networks, deauth, or injection. Third-party CYD picks are draft / not wired placeholders: they open an upstream installer and do not activate the local Install button. Android companion app: download from Projects (Wigglefish 0.4.0).
