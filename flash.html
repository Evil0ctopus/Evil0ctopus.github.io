What do “chip,” “firmware,” and “factory image” mean?
Chip
The small processor inside the board. Firmware must be built for the right chip.
Firmware
The software that runs on the board.
Factory image
A complete first-install file. It may erase the board’s existing software and saved settings.

    I need help connecting or recovering my board
    1. Use desktop Chrome or Edge and a USB cable that supports data, not charging only.
    2. Back up anything you need. A factory image may erase the board’s current software and saved settings.
    3. Connect only after the selected board and its notes match your device. If asked, follow the board maker’s instructions to enter boot mode.

    If the connection fails, unplug the board, check the cable and exact model, then try again. Never use a file made for a different chip or board. For recovery steps, open the selected project’s documentation.
